# 设置 / 档案返回修复

用户要求每页一个退出入口，并修复返回主菜单后入口按钮一直呈按下外观。

修复前在 Unity 6000.6.5f1 的正式场景播放模式中，通过指针进入、按下、抬起、点击、离开和返回事件复现：两页各有两个激活出口；返回后导航焦点回到入口，设置入口显示 `UI_Button_Main_Settings_Pressed`，档案入口显示 `UI_Button_Main_Archive_Pressed`。

根因：主菜单 `selectedSprite` 与 `pressedSprite` 指向同一张图，文字反馈也把导航选中视作按住。弹窗恢复导航焦点后，Unity 正确进入 Selected 状态，但美术配置把它显示成 Pressed。

修复：设置页保留右上角 ×；档案页保留左上返回箭头。重复底部按钮保持旧序列化引用但停用，且不参与导航。主菜单 Selected 使用默认 Sprite；反馈组件仅在鼠标悬停和按住时显示活动图与对应文字颜色。返回继续恢复导航焦点，不影响键盘再次打开页面。

`Tools/Unity/MenuReturnValidation.cs` 的 Baseline 记录旧行为，Review 每页重复三轮鼠标与键盘打开 / 返回，检查唯一出口、恢复后的默认图片、悬停反馈、文字颜色、键盘焦点与暂停设置返回。用户音量与静音值不改变。

验收结果：两页各三轮鼠标打开 / 关闭和三轮键盘提交 / 关闭全部通过；默认图片和文字颜色恢复正确，导航焦点仍恢复到入口。暂停中的设置页仍返回暂停。编辑器重新编译完成。
