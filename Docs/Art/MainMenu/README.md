# 不眠垣城 · 开始页

游戏名按用户确认使用「不眠垣城」，标语为「城不靠人管，城自己管自己。」。

## 使用

打开 `Assets/Defend/Content/Scenes/Dev/IndustrialDefense.unity`，播放后显示开始页。
美术与交互已保存到 `Assets/Defend/Content/Prefabs/UI/DefenseInterface.prefab`，无需执行制作工具。
编辑器菜单「不眠垣城 / 应用开始页美术」可重复更新开始页，不重建玩法场景。
原有正式界面制作工具也会保留此美术布局。

四个主要入口：

- 开始守望：开始新的守望，进入基地部署／准备阶段。
- 操作说明：打开项目现有操作与规则弹窗，可返回开始页。
- 垣城档案：打开背景故事、防御工事、守城者图鉴；沿用现有资料和分类。
- 设置：音乐音量、音效音量、静音即时生效并保留到下次启动；沿用已有音乐与点击音。

现有项目没有对局存档或恢复接口，因此此版本显示「开始守望」。没有虚构「继续守望」或上次波次；恢复存档的文案切换需随真实存档功能接入。

## 美术资源

资源目录：`Assets/Defend/Content/Art/MainMenu/Textures/`。

| 文件／子资源 | 用途 |
| --- | --- |
| `BG_Main_defend_01.png` | 无标题、无按钮的云海浮城背景，1672×941 |
| `UI_Logo_Main_01.png` | 透明背景「不眠垣城」金属标题 |
| `UI_Main_ButtonStates_01.png` | 1254×1254 透明按钮状态图集 |
| `UI_Button_Main_Start_Normal` / `Pressed` | 主入口玻璃金属牌 |
| `UI_Button_Main_Guide_Normal` / `Pressed` | 操作说明金属牌 |
| `UI_Button_Main_Archive_Normal` / `Pressed` | 垣城档案金属牌 |
| `UI_Button_Main_Settings_Normal` / `Pressed` | 设置金属牌 |

Guide、Archive、Settings 使用图集的同一组空白牌面，分别保存命名的 Sprite 子资源，文字为可编辑中文文本。悬停、按下会切换到青色深底状态，同时文字改为浅色。键盘焦点使用独立青色边角，默认选中「开始守望」，返回弹窗后保持默认按钮图片。装饰图片不拦截点击。

当前美术资产为临时版本，后续将替换为最终版本。

开始页按 1920×1080 构图使用相对锚点；背景等比覆盖，标题及控件等比适配。保留全局 CanvasScaler 和局内界面排版。
沿用项目中文字体与 uGUI Text，没有引入新 UI 包或外部运行时依赖。

## 生成来源与提示词

工具：Codex 内置 `image_gen.imagegen`；输入为用户提供的开始页参考图
`codex-clipboard-9fe0137c-649e-4754-9ee6-5ab2b637144d.jpg`。所有产物均已复制到项目，不依赖临时生成目录。

背景提示：编辑提供的开始页参考图，保留 16:9 云海工业浮城、青色能量通路、前景机炮和右侧机械结构的构图与光照。删除全部标题、标语、按钮文字及四块菜单牌，补全相应天空与建筑。左上保留明亮空域，右侧保留可叠加按钮的深色机械墙。可添加最多两只遥远、很小的机械兽剪影。不要任何文字、Logo、UI 或水印。不透明背景。

按钮提示：生成一张透明背景、2×2 排列的空白工业金属牌图集。左上为正常主按钮：象牙白发光玻璃屏和深色金属框；右上为按下主按钮：较深青色玻璃屏和亮青色边框。左下为正常次按钮：风化象牙白钢板、倒角切角与机械挂件；右下为按下次按钮：深灰青色钢板与青色边缘。所有牌正面朝向镜头，无文字，彼此不接触，有清晰透明间隔；匹配参考图工业材质。

Logo 提示：透明背景独立中文 Logo，只含准确四字「不眠垣城」。粗厚、锐利、几何感的深色枪钢笔画，金属倒角高光和轻微阴影，匹配参考图的工业科幻标题。不要标语、场景、边框或额外文字。
